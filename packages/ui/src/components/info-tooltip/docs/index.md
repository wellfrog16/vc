# info-tooltip

## 功能

用于展示信息提示的组件。相对于 el-tooltip，该组件进行了针对性的封装，默认使用 icon 占位提示，并且支持异步展示信息。

利用 [config-provider](../../components/config-provider) 进行全局配置，可以实现动态提示功能
